# 银魂 像素剧场（游戏素材包）

2026-09-25 用**一句话提示词**做出来的 5 分 34 秒像素风动画，B 站《claude opus大人制作 300秒看完《银魂》》（BV1HDhD6FEsv）。这里存的是它的全部可复用部分，用来日后把视频做成游戏。

- 原提示词：「给我做一个动画像素风 银魂动漫剧情的经典场景，按照顺序讲述大致故事， 包含主要人物 动画好看一点 有趣一点 场景丰富一点 直接给我视频」
- 制作：Claude Opus 5.5 在“无文件夹会话”（会话名“银魂动画像素风视频”）里先自己写引擎和参考角色（约 25 分钟），再用 Workflow 起 41 个子代理并行：角色 A–F、背景、配乐 A / B、音效、15 个场景各一个 + 各一个复查 + 角色 QA；2026-09-25 20:25 开始，23:17 出片。
- 会话自己记的用量：按 API 价折算约 352.5 美元（Opus 5.5 输出 5,765,713 token、thinking 2,983,656 token）。这是折算值，订阅不按这个付。
- 成片 mp4 不在这里：项目里有一份拷贝 `Way to AGI/02_如何使用Claude来低成本的生成视频/教程_Claude做视频/素材/展示视频/03_银魂_像素风.mp4`（253 MB，1920×1080，30 fps）。

## 数据一览

- 角色：42 个（银时、新八、神乐、定春、阿妙、登势、长谷川、近藤、土方、冲田、山崎、伊东、桂、伊丽莎白、高杉、坂本、白夜叉、松阳、小银时 / 小桂 / 小高杉、冈田似藏、月咏、日轮、晴太、凤仙、神威、星海坊主、胧、虚、茂茂、阿通、凯瑟琳、小玉、天人（猪 / 猫）、奈落、春雨、路人 ×2、托西、桂短发版）。路人另有 3 种配色，存成 `townsman__v1..3`、`townswoman__v1..3`。
- 每个角色约 33 个动作（标准 31 种 + 各自特有的，如银时的挖鼻孔 / 喝草莓牛奶 / 看 Jump，神乐的雨伞开枪，土方的挤蛋黄酱），每个动作 1–24 帧，12 fps；多数角色有 12–18 张表情 / 对话头像（定春、伊丽莎白等自定义角色只有 1 张）。
- 场景：15 个，5:34；音乐 12 首；音效 81 个。

## 怎么用

- **做游戏**：读 `角色图集\README.md`（格式 + 画布 / Phaser / Godot 用法）。
- **按分镜做关卡**：先看 `剧情分镜\分镜总表.md`，再看每个场景的 `场景分镜\sNN_*.md`。
- **改角色、加动作、重新出片**：在 `源码\` 里。`python charsheet.py gintoki` 看某个角色所有动作；`python preview.py s07 --step 0.5` 看某个场景；`python main.py` 重新渲染全片（要 ffmpeg，约几分钟）。
- **重新烘焙图集**：`python 烘焙脚本\bake_characters.py`（约 1 分钟）。

## 依赖和注意

- Python 3.12、Pillow 11、numpy 1.26、scipy（音频合成）、ffmpeg 8（出视频）。
- **字体**：`源码\engine\text.py` 写死了 `C:/Windows/Fonts/` 下的 `simsun.ttc`（字幕、12/16 px 点阵字）、`simhei.ttf`、`STXINGKA.TTF`（行楷，标题 / 篇章卡）、`FZSTK.TTF`、`simkai.ttf`——中文版 Windows 自带。换机器要有这些字体，否则字幕和标题画不出来。图集本身不依赖字体。
- 角色是《银魂》同人形象（原作：空知英秋《银魂》），画法、配乐、音效都是程序生成的原创。**只放本机**：`D:\大疆\.gitignore` 已排除整个 `游戏素材\`，不要放进公开仓库。
- 已知问题（子代理在报告里提过，没修）：银时的 `shoulder` 动作里木刀会横在脸上；`name_card` 在名字和标题相同时会重复显示名字。完整清单看 `剧情分镜\设计过程\子代理\` 里各个报告的 “Shared-file problems”。
- 原件仍在 Claude 桌面版临时工作区（`scratch-2026-09-25-336c0d`），那里的会话一删就没了；这个目录是备份，别指望原处。
