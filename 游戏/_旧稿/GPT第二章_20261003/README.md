# 银魂 像素剧场 · 游戏版（序章 + 第二章）

**双击 `index.html` 就能玩**（Chrome / Edge，不用装东西，也不用起服务器）。2D 剧情打斗：剧情用对话推进，平时可以自由走动、和街坊聊天、调查东西，走到特定地方触发战斗；战斗有血条，赢了接着剧情，输了从这场战斗重新开始。没有装备、技能、收集。

画面、角色、配乐、音效全部来自原视频工程（`..\源码`、`..\角色图集`、`..\音频`），开场动画就是原片 s00 的两段。

## 操作

| 操作 | 按键 |
|---|---|
| 移动（左右 + 前后纵深） | ← → ↑ ↓ / W A S D |
| 对话 / 调查（靠近人或东西，头顶出现 ▼ 提示） | Enter / 空格 / E |
| 推进对话 | Enter / 空格 / J |
| 攻击（连按三连击：下劈 → 上撩 → 突刺，第三下能把人打飞） | J / Z |
| 跳跃（空中按 J = 跳斩） | K / X |
| 防御（按住，挡住正面的攻击） | L / C |
| 暂停（继续 / 操作说明 / 回到标题） | Esc |

开场动画可以按 Enter 跳过。

## 内容

**序章：白夜叉**（攘夷战争，黄昏的战场）
1. 开场动画（原片：天人降临 → 攘夷战争 → 四人立于夕阳）。
2. 志士营地，自由走动：桂（不是假发，是桂）、坂本（金时 / 到宇宙做生意）、篝火边的年轻志士、放哨的志士，调查篝火、营帐、战旗。
3. 出营地 → 第一场战斗（两波天人兵）→ 往右 → 第二场战斗（一波天人兵 + **天人部队长**，大招前闪红光、喊“!!”，要防御或跳开）。
4. 桂和坂本赶到 → 旁白 → 开场动画后半（雨中的废刀令 → 「银魂」标题）。

**第一章：万事屋阿银**（现在，歌舞伎町）
1. 事务所：银时在沙发上睡觉，登势破门催三个月房租。
2. **解谜：凑房租**——调查房间（电视里的结野主播、沙发缝、草莓牛奶、办公桌、Jump、日历、挂钟、盆栽、「糖分」字画）。沙发缝里的字条：“重要的钱，藏在你最重视的东西后面”→ 答案是「糖分」字画背后的私房钱 5000 日元。
3. 交钱三选一（三个答案登势的反应都不同）→ 一脚被踢出窗外，摔在大街上。
4. 歌舞伎町自由闲逛：登势（坟前偷吃馒头的往事）、拉面店排队的客人、问洞爷湖的路人、书店店员（Jump 周一才发售）、路过的街坊、澡堂看板娘；调查柏青哥、万事屋招牌、甘味处、酒屋、高天原、豆腐店、澡堂、当铺、药铺（治天然卷的药）。
5. 登势说甘味处被收“保护费” → 往右走触发：天人混混三人 + **猪头大哥**。
6. 打完：团子店大婶、登势（这个月的房租先拿五千抵着）→ 挖鼻孔：“……今天的歌舞伎町，也很和平呢。”

**第二章：新八登场**
1. 家庭餐厅自由调查：菜单、挂钟、阿通海报、窗外乌鸦；和服务员新八交谈，使用过期优惠券点巧克力芭菲。
2. 芭菲被天人客人砸碎，餐厅两波战斗；店长宣布“新八！你被开除了！”，新八跟着银时前往道场。
3. 志村道场门口调查借条，先答错一次也可以重选；识破“利息每日三成”后，和讨债的两波战斗，新八作为不会死亡的同伴协战。
4. 道场内和阿妙对话，进入“请用～”煎蛋选项；无论吃或不吃都会倒下，随后新八加入万事屋。

台词按原作的人物性格和梗写（甜党、天然卷、Jump、洞爷湖、桂的“不是假发”、坂本的“金时”、登势和银时的相遇），大部分是新写的，不是原作原句。

## 改剧情 / 加新章节

- 剧情是一句句 `await` 写的，例如：
  ```js
  await S.say('otose', '银时！三个月的房租呢！', { expr: 'angry' });
  await S.walk('otose', 300, 168);
  await S.fight({ arena: [430, 814], waves: [[{ cid: 'amanto_pig', name: '天人混混', hp: 26 }]] });
  ```
- 加新章节：仿照 `story\chapter1.js` 写 `G.STORY.chapter2`，在 `main.js` 的 `G.CHAPTERS` 里加一项，`index.html` 引入新文件。
- **改了任何台词、加了新字以后，要重跑** `python tools\build_assets.py font data`（字库只收用到的字；缺字时控制台会提示）。
- 角色用 `..\角色图集` 里的 id（42 个角色 + 路人配色 + 新八围裙 `shinpachi__apron`；围裙版是给第二章烘的，还没导入，跑 `python tools\build_assets.py chars data` 才进游戏）；地图背景目前有：战场（黄昏）、事务所、歌舞伎町大街（白天）。新背景在 `build_assets.py` 的 `build_bg()` 里从原工程的 bg 模块导出。

## 重新生成资源 / 测试

```text
python tools\build_assets.py                  # 角色、背景、UI、音频、字库、data.js（几秒）
python tools\build_assets.py video            # 开场动画（约 30 秒）
python tools\playtest.py all --lose           # 自动通关序章到第一章（第一场战斗故意输一次）
python tools\playtest.py ch2                 # 自动验证第二章（含借条答错与战斗）
```

自动测试用的是 Playwright 自带的 Chromium（2026-10-03 跑通：序章 + 第一章 78 句对话，控制台 0 报错）。
