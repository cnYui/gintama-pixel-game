# 银魂 像素剧场 · 游戏版（序章到终章，全 15 章）

**双击 `index.html` 就能玩**（Chrome / Edge，不用装东西，也不用起服务器）。
**手机 / 平板也能玩（横屏，屏幕上有按键）**：电脑上双击 `手机试玩.bat`，手机和电脑连同一个 Wi-Fi，手机浏览器打开窗口里印出来的网址，详见下面「手机 / 平板（触屏）」。

这是一个 2D 剧情打斗游戏：

- 剧情用对话推进；
- 平时可以自由走动、和街坊聊天、调查东西；
- 走到特定地方触发战斗；战斗有血条，赢了接着剧情，输了从这场战斗重新开始；
- 没有装备、技能、收集。

画面、角色、配乐、音效全部来自原视频工程（`..\源码`、`..\角色图集`、`..\音频`）。开场动画就是原片 s00 的两段；每一章对应原片的一个分镜场景（s01–s13 是第一章到第十三章，s14 是终章），原片的镜头（特写、冲击帧、名牌、集结的合影、日出……）照原片的画法在游戏里重做。

## 操作

| 操作 | 按键 |
|---|---|
| 移动（左右 + 前后纵深） | ← → ↑ ↓ / W A S D |
| 对话 / 调查（靠近人或东西，头顶出现 ▼ 提示） | Enter / 空格 / E |
| 推进对话 | Enter / 空格 / J |
| 攻击（连按三连击：下劈 → 上撩 → 突刺，第三下能把人打飞） | J / Z |
| 跳跃（空中按 J = 跳斩） | K / X |
| 防御（按住，挡住正面的攻击） | L / C |
| 暂停（继续 / 操作说明 / 回到标题） | Esc |

- 标题画面有三项：从序章开始 / 选择章节 / 操作说明。
- 从哪一章开始，打完会接着进下一章。
- 开场动画可以按 Enter 跳过。
- 鼠标 / 手指也能用：点一下画面 = 推进对话；标题、选章节、暂停菜单、选项框直接点哪项选哪项（2026-10-06 起；点在空处不算确认，点暂停菜单外面 = 继续游戏）。

## 手机 / 平板（触屏）

2026-10-06 加的：不改剧情、不改战斗，只是在屏幕上画出按键，把手指翻成上面那张表里的键盘输入。

**怎么在手机上玩**

1. 电脑上双击游戏目录里的 `手机试玩.bat`（就是 `python tools\serve_phone.py`，开一个只给局域网用的小服务器）。第一次 Windows 会问“是否允许 Python 访问网络”，点允许（专用网络）。
2. 手机和电脑连同一个 Wi-Fi，手机浏览器打开窗口里印出来的网址（一般 `http://192.168.x.x:8000/`）。
3. 横着拿。点右上角 ⛶ 全屏（安卓 Chrome 会顺便锁横屏）；iPhone 的 Safari 没有网页全屏，要点“分享 → 添加到主屏幕”，再从桌面图标打开。
4. 不能直接把 index.html 发到手机上点开：file:// 下画面和声音会被浏览器拦；而且 iPhone 放视频 / 音频要服务器支持分段请求，Python 自带的 http.server 不支持，`serve_phone.py` 里补上了。

**屏幕上的按键**（有触屏的设备自动出现；接上实体键盘按一下键就收起来，再碰屏幕又出来）

| 位置 | 按键 | 对应 |
|---|---|---|
| 左下 | 方向盘（手指放上去、滑到哪儿朝哪儿走，8 个方向；选菜单时按住 ↑ ↓ 会连着走） | ← → ↑ ↓ |
| 右下 | **J 攻击**（连点三连击；对话、菜单里 = 确认） | J |
| 右下 | **K 跳跃**（空中点 J = 跳斩） | K |
| 右下 | **L 防御**（按住） | L |
| 右下 | **E 调查 / 确认**（靠近人或东西时会跳动提醒） | E |
| 右上 | ⏸ 暂停（选章节、说明页里 = 返回）、⛶ 全屏 | Esc |
| 画面任意处 | 点一下 = 推进对话 / 跳过开场动画 | Enter |

- 按键名字（J K L E）和游戏里提示文字一致，所以“按 J 停下转轮”“按住 L 防御”在手机上照样对得上；操作说明页和少数提示在触屏下会换成触屏的说法。
- **按场景自动显示**：对话 / 旁白 / 过场时方向盘和 J K L E 都收起来（不挡字，点屏幕继续）；连按 / 看准时机的小游戏只留 J；选项和菜单只留方向盘 + J / E（也可以直接点选项，点菜单外 = 取消）；自由走动时 J、L 暗着；战斗时全亮。
- 按钮压在画面上的地方，提示框改放上面（名牌滑进来时先等名牌走了再出）、选项框往左挪、计时放到暂停钮下面（`G.touch.safe` 记着按键盖到了画面的哪里）。宽屏手机（20:9）的黑边够放按键，就不压画面。
- 手离开屏幕 2.5 秒按键会淡下去（少挡画面），一碰就回来。
- 按键太大 / 太小：暂停菜单里有一项“按键大小”（小 / 中 / 大，点一下换一档，记在这台手机里）。
- 竖着拿会出“请把手机横过来玩”，游戏停住不走。
- 网址后面加 `?touch=1` 能在电脑上强制显示按键（调试、截图），`?touch=0` 强制不显示。
- 自测：`python tools\touchtest.py [宽 高]`（Chromium 模拟手机横屏，真的去点、去按住方向盘，看角色走不走、J K L 出不出招、暂停菜单能不能点……）。

## 内容

**序章：白夜叉**（攘夷战争，黄昏的战场）

1. 开场动画（原片：天人降临 → 攘夷战争 → 四人立于夕阳）。
2. 志士营地，自由走动：
   - 能聊天的人：桂（不是假发，是桂）、坂本（金时 / 到宇宙做生意）、篝火边的年轻志士、放哨的志士；
   - 能调查的东西：篝火、营帐、战旗。
3. 出营地 → 第一场战斗（两波天人兵）→ 往右 → 第二场战斗（一波天人兵 + **天人部队长**）。部队长放大招前会闪红光、喊“!!”，要防御或跳开。
4. 桂和坂本赶到 → 旁白 → 开场动画后半（雨中的废刀令 → 「银魂」标题）。

**第一章：万事屋阿银**（现在，歌舞伎町）

1. 事务所：银时在沙发上睡觉，登势破门催三个月房租。
2. **解谜：凑房租**。
   - 能调查：电视里的结野主播、沙发缝、草莓牛奶、办公桌、Jump、日历、挂钟、盆栽、「糖分」字画。
   - 沙发缝里有张字条：“重要的钱，藏在你最重视的东西后面”。答案是「糖分」字画背后的私房钱 5000 日元。
3. 交钱三选一（三个答案登势的反应都不同）→ 一脚被踢出窗外，摔在大街上。
4. 歌舞伎町自由闲逛。
   - 能聊天的人：登势（坟前偷吃馒头的往事）、拉面店排队的客人、问洞爷湖的路人、书店店员（Jump 周一才发售）、路过的街坊、澡堂看板娘。
   - 能调查的地方：柏青哥、万事屋招牌、甘味处、酒屋、高天原、豆腐店、澡堂、当铺、药铺（治天然卷的药）。
5. 登势说甘味处被收“保护费” → 往右走触发战斗：天人混混三人 + **猪头大哥**。
6. 打完：团子店大婶、登势（这个月的房租先拿五千抵着）→ 挖鼻孔：“……今天的歌舞伎町，也很和平呢。”

**第二章：新八登场**（家庭餐厅 → 歌舞伎町 → 黄昏的志村道场）

1. **家庭餐厅**，自由调查。
   - 能调查：厨房门、挂钟、窗外（窗台上的乌鸦）、海报、盆栽。
   - 能聊天：服务员（新八）、三个天人客人。
   - 和服务员说话：拿第一章抽屉里那张过期优惠券点巧克力芭菲，新八用员工折扣帮你垫上。
2. 坐到吧台的空凳子上：芭菲上桌 → 猪头客人跺脚“地球猴子！上菜慢死了！” → 一拳砸吧台，芭菲慢动作飞出去摔烂。
3. 一片死寂，乌鸦从窗外飞过，“阿～”“呆～”。
4. 银时的眼睛特写：死鱼眼 →（锵！）认真。
5. 餐厅战斗：第一波是三个天人客人，第二波是**猪头客人**。最后一下把他打穿后墙，墙上留下猪形的洞，人从洞里飞出去变成星星。
6. 店长（厨师帽）踹开厨房门：“新八！你被开除了！”
   - 托盘落地，新八石化；名牌：志村新八。
   - 银时挖着鼻孔要走，新八吐槽：“你给我等一下！！”
   - 银时一记鼻屎弹到他眼镜上。
   - 新八脱下围裙跟了出来。
7. **歌舞伎町**：新八一路跟在身后，讲道场的债。街坊们换了第二章的台词；往右走到底就是道场。
8. **志村道场门口（黄昏）**，**解谜：借条**。
   - 讨债的把借条贴在门上。先调查借条，再找讨债头目谈判，选出借条哪里不对。
   - 答错时新八会吐槽，可以重选。答案是“利息每日三成”。
9. 门口战斗：**新八当同伴一起打**，他被打倒过一会儿会自己爬起来，不会死。打到讨债头目只剩一点血时，阿妙出场，一拳把他打成星星。名牌：志村妙。
10. **道场里**：自由调查（匾额、挂轴「一心」、木刀架、拉门），坐到坐垫上开饭。
11. 阿妙的“煎蛋”：特写「※本品为煎蛋」→ 选吃 / 不吃（不吃的话阿妙会笑着再问一次）→ 嘎嘣 → 银时往后倒、灵魂出窍。
12. 新八站起来（光束、樱花）：“我要跟着这个人，找回我的武士道！” →「志村新八 加入了万事屋！」→ 章末。

## 改剧情 / 加新章节

- 剧情是一句句 `await` 写的，例如：
  ```js
  await S.say('otose', '银时！三个月的房租呢！', { expr: 'angry' });
  await S.walk('otose', 300, 168);
  await S.fight({ arena: [430, 814], waves: [[{ cid: 'amanto_pig', name: '天人混混', hp: 26 }]] });
  ```
- 第二章加的剧情工具：

  | 工具 | 作用 |
  |---|---|
  | `S.animate(秒, (k) => …)` | 逐帧动画（芭菲飞出去、托盘落地、鼻屎） |
  | `S.prop({...})` / `S.unprop` | 剧情里的小道具 |
  | `S.insert(画法)` | 全屏特写（眼睛、煎蛋） |
  | `S.impact()` | 冲击帧 |
  | `S.notice({...})` | “××加入了万事屋！”提示框 |
  | `S.follow(人)` | 让同伴跟着走 |
  | `S.setStage(地图, { carry: [...] })` | 换地图时带上同伴 |
  | `S.state(键, 值)` | 改地图的画面状态（墙洞、乌鸦、光束、樱花） |

录屏要点：

- 游戏用 `http://` 打开（脚本自己起本地服务器）；`file://` 下画布和音频算跨域，录不出来。
- 窗口就是游戏原尺寸 384×216，转 mp4 时最近邻放大 5 倍到 1920×1080，像素不糊。
- 画面用 `captureStream()`，**不要传帧率**：传 60 的话浏览器按“距上一帧满 1/60 秒”限流，帧间隔一抖就丢帧，只剩 51 帧左右。
- 三条（画面 + 混音、BGM、音效）同一时刻开录，拖进剪辑软件都对齐 0 秒就是同步的。

自动测试用的是 Playwright 自带的 Chromium：自动推进对话、走位、打架、按小游戏，按台词或剧情里标的镜头（`G.dbg = { shot }`）截图；结果里有每次换地图的时间（`trace`），哪里卡住一眼能看出来。
